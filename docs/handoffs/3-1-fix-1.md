## Requirements

### F1. No clipping (SHOULD)
In `.viewport`, `overflow: hidden` clips everything outside the strip's box, and the strip is exactly one cell tall (`min-height: var(--case-cell-width)`, cells of the same height). As a result:
- the bottom `--shadow-chunky-sm` offset of every card is cut off
- the revealed winner's `translateY(-space-1)` lift is cut off at the top

Fix: give the strip room vertically, e.g. `padding-block: var(--space-3)` on `.viewport` or `.strip`.
- The horizontal math must stay unchanged. Measure only widths, and do not add horizontal padding to the strip.
- The marker still spans the full viewport height.

### F2. Desktop width (SHOULD)
`.content` uses `width: min(100%, var(--content-max-width))`, where the token is 30 rem. The `max-width: 48rem` in the media query cannot widen it. On desktop the strip is therefore about 3 cells wide.
- Add one layout token to `tokens.css`: `--content-wide-max-width: 60rem;`. Place it next to `--content-max-width`, with a comment that it is for wide screens such as the case-opening stage.
- In `CaseOpening.module.css`, from `48rem` up, set `.content { width: min(100%, var(--content-wide-max-width)); }`, and remove the ineffective `max-width: 48rem`.
- Desktop should show about 6 cells. Phones are unchanged.

### F3. One preview plan (SHOULD)
`CaseOpening.tsx` rebuilds `buildAnimationPlan(select(options, CASE_PREVIEW_SEED), options)` and repeats the `ready ? preview : state.plan` logic that the hook already has.
- `useCaseOpening` returns the displayed `plan` as well: `{ state, plan, open, viewportRef, stripRef }`.
- `CaseOpening.tsx` uses `plan` from the hook. Remove its `previewPlan` memo and the `select`/`buildAnimationPlan` imports.
- Stop exporting `CASE_PREVIEW_SEED`; it becomes a module constant of the hook.

### F4. One source for the cell size (SHOULD)
`--case-cell-width` is set on `.viewport` (`CaseCarousel.module.css`, phone + `48rem` media) **and** again on `.item` (`CaseItem.module.css`, `48rem` media). Keep it only on `.viewport`; the items inherit it. Delete the media block in `CaseItem.module.css`.

### F5. Remove the unused `reset` event (NICE)
Nothing dispatches `reset`. The architect's handoff specified it too early. Remove it from `CaseOpeningEvent` and from the reducer. Phase 5 adds it back if the builder needs it.

### F6. Reduced-motion class contract (NICE)
`useCaseOpening.ts` imports `CaseCarousel.module.css` only to get the `reducedMotion` class name, which couples the hook to another component's stylesheet.
- Instead, the hook sets `strip.dataset.motion = 'reduced'` and deletes it when clearing.
- `CaseCarousel.module.css` styles `.strip[data-motion='reduced']` with the same token transition.
- Remove the CSS-module import and the non-null assertion from the hook.

### F7. Small CSS/markup nits (NICE)
- `CaseOpening.module.css`: `.result p { min-height … }` duplicates `.result { min-height … }`. Keep only the one on `.result`.
- `CaseCarousel.tsx`: the marker has `aria-hidden` inside an already `aria-hidden` viewport. Remove the inner one.
