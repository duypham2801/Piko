## Context

7-5 (`b8106bd` on `fix/dev-lan-access`) made LAN access to the dev web app opt-in:
- `DEV_WEB_BIND` + `compose.dev.lan.yaml` publish port 5173 on one LAN IP. `127.0.0.1:5173` is always kept.
- `DEV_LAN_ORIGIN` is a single extra origin. The API's mutation guard and Hono `csrf()` accept it, and only in `development`.

The owner also wants to open dev over **Tailscale**. Decision **D-034** (amended, see `docs/DECISIONS.md`) settles how:
- **Tailscale Serve:** the owner runs `tailscale serve --bg 5173` on the host. This gives `https://dp-1.tailfeab26.ts.net` (HTTPS, a stable name, any device in the tailnet) and proxies to `http://127.0.0.1:5173`.
  - Docker publishes no extra port, so 5173 stays on localhost for Tailscale.
  - `DEV_WEB_BIND` remains only for plain LAN access by IP.
- **The single extra origin becomes a list.** This proxy needs two settings:
  - the API must accept writes from `https://dp-1.tailfeab26.ts.net`;
  - Vite must accept that `Host` header. Vite rejects requests whose `Host` is not localhost or an IP unless the host is in `server.allowedHosts`, and answers them with "Blocked request".

  Any later reverse proxy in front of the dev server needs the same two settings, so one list drives both.
- **Prod is unaffected.** The future prod domain (Phase 9) keeps using `APP_ORIGIN` through Caddy. Nothing in this task touches prod.

### 1. API env (`apps/api/src/env.ts`)

- **Remove `DEV_LAN_ORIGIN` completely.** The branch is not merged yet, so no compatibility alias is needed.
- **Add `DEV_EXTRA_ORIGINS`:** an optional string that parses to `string[]`, with `[]` when it is absent or empty.
  - Split on `,`, trim each entry, and drop empty entries.
  - Each entry must be a valid `http:` or `https:` URL that is a **bare origin**, meaning `new URL(entry).origin === entry`. No path, no trailing slash, no query.
  - Reject anything else with an issue on path `['DEV_EXTRA_ORIGINS']` whose message names the bad entry.
- **Keep the existing rule:** a non-empty list is rejected unless `NODE_ENV === 'development'`, with the message `DEV_EXTRA_ORIGINS is only allowed in development.`
- The inferred `ApiEnv['DEV_EXTRA_ORIGINS']` type is `string[]`.

  - Do **not** use `true`.
