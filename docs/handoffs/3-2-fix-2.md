## Context

In the visual review of 3-2, the owner found that the marker always stops in about the same part of the winner cell. That is correct for the current setting: `ANIMATION_PLAN_DEFAULTS.stopBand` is `0.6`, so the stop offset is uniform within ±0.3 cell, and the marker always lands between 20 % and 80 % of the cell.

The architect measured 6 spins at 0.21, 0.51, 0.55, 0.66, 0.72 and 0.79 of the cell. To the eye that reads as "always near the middle".

The owner chose (D-026, updated): `stopBand = 0.9`. The offset stays **uniform** within ±0.45 cell, so the marker lands between 5 % and 95 % of the winner cell.
- It is still a uniform random offset from the plan PRNG.
- It is **not** biased towards the edges. An engineered near-miss is forbidden (D-010).
