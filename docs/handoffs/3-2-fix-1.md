## Context

Handoff 3-2 is committed on branch `feat/3-2-celebration` (commit `feat(web): reveal celebration with winner pop, confetti and winner panel`).

The architect's review accepts:
- the tokens
- the pop/dim styles
- the deterministic confetti and its keyframes
- the accent winner panel and the live region
- reduced motion
- `make check` (42 domain tests, 7 api tests)
- the literal greps
- 80.18 kB gz

Headless Chrome measured this, however:

| viewport | `.content` left / width | `.stage` / `.viewport` width |
|---|---|---|
| 360 px | 3552 px / 480 px | 7552 px |
| 1280 px | 4592 px / 960 px | 10080 px |

**The whole screen renders off-screen, so the page looks blank on phone and desktop.** Screenshots show only the cream background.

The cause:
- The new `.stage` wrapper is the grid item now. With the default `min-width: auto` it grows to the strip's `max-content` width (about 60 cells).
- Before 3-2, the grid item was the carousel viewport itself, and `overflow: hidden` gave it a zero automatic minimum.
- `overflow-x: clip` on `.screen` then hid the scrollbar. `scrollWidth` therefore looked fine and masked the bug.

The architect verified the fix in the browser (`.stage { min-width: 0 }` without the clip):
- 360 px: `.content` 16/328, `scrollWidth` 360, panel 328 wide
- 1280 px: `.content` 160/960, `scrollWidth` 1280

## Requirements

### F1. Stage must not grow to the strip width (MUST)
In `CaseOpening.module.css`:
- add `min-width: 0;` to `.stage`, with the comment `/* grid item: do not grow to the strip's max-content */`
- **remove** `overflow-x: clip` from `.screen`

The confetti burst fits inside the screen without the clip; the architect verified `scrollWidth` equals the viewport width at 360 px and 1280 px after the burst. Do not reintroduce any `overflow` on `.screen` to hide overflow.

### F2. `CaseItem` derives its own state (SHOULD)
`dimmed` is always `revealed && !isWinner`. The three booleans are redundant (the 3-2 handoff specified it; architect mistake).
- Remove the `dimmed` prop from `CaseItem` and from `CaseCarousel`.
- In `CaseItem`: `[styles.item, revealed && (isWinner ? styles.winner : styles.dimmed)].filter(Boolean).join(' ')`.

### F3. Confetti class list (SHOULD)
`styles[piece.shape]` resolves to `undefined` for `'strip'`, because there is no `.strip` class. That leaves a stray value in `className`, and the `ConfettiShape` type has a variant nothing uses.
- Replace `shape: ConfettiShape` with `dot: boolean` (`index % 4 === 0`). Delete the `ConfettiShape` type.
- className: `[styles.piece, styles[piece.color], piece.dot && styles.dot].filter(Boolean).join(' ')`. This is the project pattern.

### F4. Logical alignment (NICE)
`.winnerDetails`: `text-align: start` instead of `left`.
