## Context

6-2 (the two commits on branch `feat/6-2-result-actions`) added the result actions. The architect reviewed it:

  - with `?off=`, the saved snapshot has those options as `enabled: false`
  - every save returns `201`

One structural issue remains.

**The options used for a spin live in a separate ref (`spinOptionsRef`).**
- Each caller of `open` must remember to set it first: `spinAgain` and `rejectWinner` do this today.
- A future caller that forgets would save a snapshot that does not match the result. The server would reject it (`result_mismatch`), and the user would only see the generic save error.
- The options belong to the result. They should travel with it in the state machine, the way `plan` and `result` already do.

## Requirements

### S1 — Options in the state
**`caseOpeningState.ts`:**
- The `open` event carries `options: readonly DecisionOptionData[]`.
- The `spinning` and `revealed` states keep it next to `plan` and `result`.
- The reducer's transitions are otherwise unchanged.

**`useCaseOpening.open(spinOptions = pool)`:**
- dispatches `{ type: 'open', plan, result, options: spinOptions }`
- uses the same `spinOptions` for `select` and `buildAnimationPlan`, as today

**`CaseOpening`:**
- Delete `spinOptionsRef` and every write to it.
- `saveResult` sends `options: state.options`.
- Result, plan and options now come from one state object, so they cannot disagree.

### N1 — Exclusion helper
The mapping "options with excluded ids set to `enabled: false`" is written twice: in the `pool` memo and in `rejectWinner`.
- Write it once, as a small module-level function in `CaseOpening.tsx`, e.g. `excludeOptions(options, excludedIds)`.
- Use it in both places.

### N2 — Clean-ups
- **`.historyStatus`:** remove `min-height: var(--tap-target-min)` and the `.historyStatus:empty` rule.
  - The status line is text, not a tap target.
  - The `:empty` rule only cancels that min-height.
- **Rename `spinAgain` to `spin`:** the handler also serves "Mở case", not only "Mở lại". This is the component's local callback; the i18n key `spinAgain` stays.
