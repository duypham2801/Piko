## Requirements

### S1 — POST response
In `routes/history.ts`, `POST /` returns `c.json(entry, 201)`, where `entry` is the typed `HistoryEntryData` from the service.
- Remove `HistoryEntry.parse(...)` and the now-unused `HistoryEntry` import.
- Reason: the service already builds a typed value. The decisions routes do not re-validate their responses either. The route tests parse the responses.

### S2 — `match.test.ts`
- **Rewrite the third test** ("rejects candidates that differ from enabled options"):
  - Run `select` with all three options enabled.
  - Then check the result against the same options with **only one** of them sent as `enabled: false`, so two stay enabled.
  - This way `select` runs and the mismatch comes from `candidateIds`, not from a throw. The assertion is still `false`.
- **Add a fourth test:** with fewer than two enabled options (e.g. all disabled), `matchesSelection` returns `false` instead of throwing. This is what the current third test actually covers.

### S3 — Pruning
In `createHistoryEntry`:
- Select only the overflow ids: the same `where` and `orderBy` (`created_at desc, id asc`) plus `.offset(DECISION_LIMITS.maxHistoryEntriesPerUser)`.
- Delete those ids when there are any.
- Drop the `.slice(...)` on the full id list. The prune must give the same result as before.

### S4 — Tests
- `routes/history.test.ts`: delete the test "returns only the requested number of newest entries".
  - The `?limit=1` path is already covered by "creates a valid entry and returns typed history responses".
  - Its two POSTs can share a millisecond, so it cannot assert which entry is newest. The service test covers ordering with injected `now` values.
- `services/history.service.test.ts`:
  - In `makeHistoryInput`, type the `source` parameter as `HistorySourceInputData` from `@piko/domain`, instead of the hand-written union.
  - In "cascades history entries when the user is deleted", remove the `decisions` table assertion. That test creates no decision, so the assertion proves nothing. Remove the `decisions` import if it becomes unused.
