## Requirements

### D1 — Dividers
**`tokens.css`:**
- Add `--border-width-hairline: 1px` next to `--border-width-thin`.
- Add `--color-divider` next to `--color-border`:
  - `color-mix(in srgb, var(--palette-navy-900) 15%, transparent)`
  - Use the same navy palette variable that `--color-backdrop` uses.
  - Adjust the percentage between 12 % and 20 % if needed, so that the line is clearly visible on `--color-surface` but much lighter than the outline.

**`DesignPage.tsx`:**
- Add `--color-divider` to the color list.
- Add `--border-width-hairline` to the border-width list. Label it "Hairline".

**`HistoryList.module.css`:**
- The `.item + .item` divider becomes `var(--border-width-hairline) solid var(--color-divider)`.

### C1 — `formatHistoryTime`
- Remove `localDayKey` and its `formatToParts` parsing.
- Compare **calendar days** with the local `getFullYear()`, `getMonth()` and `getDate()` of the two dates, for example with a small `isSameLocalDay(a, b)` helper.
- "Yesterday" is the local day before `now`, as it is today.
- Keep both `Intl.DateTimeFormat('vi-VN', …)` formatters for the output.
- The output strings must not change.

### C2 — Home section rules
- In `HomePage.module.css`, `.recent`, `.yourDecisions` and `.quickPicks` each repeat `display: grid; gap: var(--space-3);`.
- Write those rules once, with a grouped selector.
- Keep the class names used by `HomePage.tsx`.
