## Requirements

### F1. Winner highlight only after the stop (MUST)
`styles.winnerCell` is applied whenever `index === plan.winnerIndex`. The winner cell is therefore outlined in the idle state and **during the whole spin**, which spoils the spin and makes the owner's feel review meaningless.
- Apply the winner class only when `hasFinished` is true and the index is the winner index.
- Starting a new Play/Replay or changing the pool or params removes the outline again. `setHasFinished(false)` is already called in these paths; verify that it still is.

### F2. Readout element owned by refs only (SHOULD)
The `<pre ref={readoutRef}>` renders React text children (`elapsed 0 ms / {plan.durationMs} …`), and the frame loop also replaces its content via `textContent`. React then keeps updating detached text nodes. This is fragile, and it breaks as soon as the structure changes.
- Render `<pre className={styles.readout} ref={readoutRef} />` with **no children**.
- The existing `[plan]` effect already calls `writeReadout(plan, 0, plan.startPosition, 0)` when idle, so the initial text still appears.

### F3. ARIA on generic elements (SHOULD)
`aria-label` is not allowed on a `div` without a role. This is the same rule as in 1b-2-fix-1 C2.
- Viewport: add `role="group"` and keep `aria-label="Case strip preview"`.
- Cells: remove `aria-label`. The label text is already visible and the emoji is `aria-hidden`. Keep `title` as the tooltip for truncated labels.

### F4. Remove the redundant initial plan memo (NICE)
`initialPlan` is a `useMemo` on `activePool`, but it only seeds `useState` once. On pool changes, the `[activePool, params]` effect builds the plan anyway.
- Replace it with a lazy initializer: `useState(() => createPlan(demoOptions.slice(0, DEFAULT_POOL_SIZE), INITIAL_SEED, ANIMATION_PLAN_DEFAULTS))`.
- Define `DEFAULT_POOL_SIZE = 8` once, and use it for the `poolSize` initial state too.

### F5. Option lookup and class merge (NICE)
- Every cell calls `activePool.find(...)`, which is about 60 × 20 lookups per render. Build one `useMemo` `Map` from id to option over `activePool`, and use it for the cells and for `winner`.
- Cell class: use the project's pattern `[styles.cell, isWinnerShown && styles.winnerCell].filter(Boolean).join(' ')` instead of the template string with `: ''`.

### F6. Strip height (NICE)
The viewport is `calc(var(--space-8) * 5)` (20 rem) tall, while cells are 8 rem wide. That makes tall, narrow cells, and the playground does not resemble a case strip.
- Set the viewport height to `calc(var(--space-8) * 2.5)` (10 rem), so cells are close to square.
- Check that the emoji and label still fit at pool size 20 and at a phone width of about 360 px.
